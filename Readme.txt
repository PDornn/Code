API de Contador de Visitas
Pré-requisitos
Node.js instalado

NPM (geralmente vem com o Node.js)

Instalação e Execução
Instale as dependências:

bash
npm install express
Execute o servidor:

bash
node nome-do-arquivo.js
Acesse os endpoints:

Visualizar visitas anteriores: GET http://localhost:3000/

Incrementar contador de visitas: GET http://localhost:3000/visitas

O servidor estará rodando na porta 3000.
